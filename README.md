# Content Automation Engine

Repositório de planejamento de um sistema para transformar conteúdo autorizado em pacotes de publicação, com revisão humana, distribuição controlada e aprendizado por métricas.

O projeto está na fase de definição do MVP. **Ainda não há aplicação implementada.**

## Documentos principais

Leia [docs/CONTENT_AUTOMATION_MVP_PROJECT.md](docs/CONTENT_AUTOMATION_MVP_PROJECT.md) para conhecer visão, escopo, arquitetura proposta, riscos, critérios de sucesso e backlog priorizado.

As regras estão em [AGENTS.md](AGENTS.md). O trabalho usa o
[fluxo econômico](docs/PROJECT_WORKFLOW.md), o
[roadmap](docs/TOPIC_ROADMAP.md) e o
[registro de R01](docs/R01_DISCOVERY_BASELINE.md).
