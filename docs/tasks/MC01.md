## Objetivo

Adicionar providers cloud sem mudar domínio, jobs ou frontend.

### MC01.1 --- Provider capability matrix

Documentar diferenças reais da API oficial escolhida: auth, modos,
duração, polling/webhook, outputs e custos.

### MC01.2 --- MiniMaxCloudAdapter contract mapping

Mapear contrato MKTauto → API oficial sem alterar `VideoGenerationPort`.

### MC01.3 --- Submit

Request cloud + autenticação segura; teste fake.

### MC01.4 --- Status

Normalizar estado externo para estados do job MKTauto.

### MC01.5 --- Result

Baixar/referenciar resultado e persistir no storage existente.

### MC01.6 --- Error/timeout/rate-limit

Normalizar falhas sem vazar payload/segredo.

### MC01.7 --- Provider selection config

Selecionar local/cloud por configuração/política existente, não por
frontend.

### MC01.8 --- Cost telemetry

Registrar custo somente quando houver evidência suficiente.

### MC01.9 --- Smoke opt-in

Chamada oficial real explicitamente autorizada.
