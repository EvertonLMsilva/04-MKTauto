# FE01 --- Frontend Contract / React

## Objetivo

Manter UI desacoplada dos providers e permitir migração futura para
React sem mudar domínio.

### FE01.1 --- API inventory

Mapear endpoints reais já existentes e evitar duplicação.

### FE01.2 --- Job create/status contract

Frontend recebe job ID/estado; nunca `prompt_id` do ComfyUI.

### FE01.3 --- Media input contract

Upload/referência por API MKTauto.

### FE01.4 --- VideoPlan API

Criar/consultar/editar/aprovar plano.

### FE01.5 --- Current UI integration

UI atual consome os contratos estáveis.

### FE01.6 --- Progress UX

Exibir estado; percentual somente quando não nulo.

### FE01.7 --- Error UX

Erros públicos sanitizados e acionáveis.

### FE01.8 --- React boundary

Definir cliente/API layer; sem lógica MiniMax/ComfyUI.

### FE01.9 --- React migration slice

Migrar uma tela/fluxo por vez, preservando API.

### FE01.10 --- Optional realtime

Avaliar SSE somente se polling causar problema real; WebSocket não é
default.
