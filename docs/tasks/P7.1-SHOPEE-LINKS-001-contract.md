# P7.1-SHOPEE-LINKS-001 — contrato e política local

Fonte pública oficial consultada em 2026-10-16, sem autenticação:
https://open-api.affiliate.shopee.com.br/explorer/v2 (`SCHEMA` embutido).

- Operação: mutation `generateShortLink`, argumento obrigatório `input: ShortLinkInput`.
- `ShortLinkInput.originUrl`: String obrigatório.
- `ShortLinkInput.subIds`: lista opcional de String. Descrição oficial:
  “Sub id in utm content in tracking link, it has five sub ids”.
  O renderer não explicita nulabilidade de elementos; a validação local rejeita null.
- Retorno `ShortLinkResult`: `shortLink: String!`, `longLink: String!`.
  Esta implementação seleciona somente shortLink; não gera outra operação para longLink.
- O schema não enumera erros específicos desta mutation. O transporte compartilhado
  sanitiza HTTP/GraphQL errors; dados parciais com errors são descartados.

Mutation fixa com variável `$input: ShortLinkInput!`. O ID de oferta é correlação
interna textual e não integra os argumentos remotos. Nenhum consumidor fornece GraphQL.

O schema define originUrl como String, sem listar hosts ou formatos de caminhos.
Portanto não há evidência de uma allowlist oficial completa. A política **local**
restritiva aceita apenas HTTPS, hosts exatos brasileiros `shopee.com.br` e
`s.shopee.com.br`, caminho não vazio/não raiz, sem porta explícita, credenciais,
fragmentos, caracteres de controle, barras invertidas, parâmetros de segredo ou
destino de redirect. O retorno é restrito a `s.shopee.com.br`.
Não seguir URLs, resolver redirects nem baixar conteúdo para validá-las.
Outros hosts/formatos, inclusive possíveis aliases legítimos, ficam pendentes
de comprovação e são rejeitados. Aceitação efetiva pelo servidor não foi testada LIVE.

Limites locais conservadores: URL até 2048 caracteres, ID de correlação até 128,
0–5 SubIDs, cada um com 1–50 caracteres ASCII alfanuméricos, `_` ou `-`.
Tamanhos e alfabeto não são atribuídos à Shopee. A ausência de subIds é preservada
como null no resultado interno; uma lista explicitamente vazia permanece [].
Os SubIDs preservados são os enviados, não uma confirmação de tracking pelo servidor.

O resultado preserva a origem, shortLink retornado, correlação e proveniência.
Não constitui evidência automática de associação, direitos, aprovação ou receita.
O fake permanece determinístico; seu caminho anterior de geração por ID é preservado.
O provider NestJS continua fake por padrão e rejeita seleção live nos fluxos normais.

Sem persistência, novos endpoints ou efeitos comerciais locais. A instância do
transporte reserva uma única tentativa, inclusive entre leituras e mutações.
Timeout 10s e limite de resposta 256 KiB; sem redirects ou retries automáticos,
inclusive após timeout (resultado remoto potencialmente indeterminado).
Esta task é exclusivamente offline: zero requisições autenticadas, credenciais
de testes sintéticas e custo de API autenticada não incorrido. Custos LIVE não aferidos.
