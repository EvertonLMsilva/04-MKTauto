# VG00 --- Video Generation Foundation

## Objetivo

Criar a fronteira estável que permite trocar MiniMax local/cloud e UI
sem contaminar o domínio.

### VG00.1 --- Levantamento mínimo do contrato existente

-   P0; depende: nenhuma.
-   Localizar somente contratos/orquestrações atuais de mídia, render e
    jobs que possam ser reutilizados.
-   Saída: evidência curta para preencher as tasks seguintes.
-   NÃO implementar.

### VG00.2 --- VideoGenerationPort

-   P0; depende: VG00.1.
-   Definir capacidade e input/output mínimos compatíveis com o projeto
    real.
-   Não incluir tipos ComfyUI/MiniMax.
-   TDD de contrato.

### VG00.3 --- VideoGenerationJob contract

-   P0; depende: VG00.1.
-   Identidade, provider abstrato, request, resultado/erro e estados
    normalizados.
-   Sem UI e sem provider real.

### VG00.4 --- State transitions

-   P0; depende: VG00.3.
-   `queued → preparing → generating → processing → completed|failed`.
-   Enumerar e testar transições; sem progresso inventado.

### VG00.5 --- Persistência/idempotência do job

-   P0; depende: VG00.3--VG00.4.
-   Reusar padrões existentes quando comprovados.
-   Retry compatível não duplica geração lógica.

### VG00.6 --- Application service

-   P0; depende: VG00.2--VG00.5.
-   Criar/consultar job e delegar à porta sem conhecer provider.
-   Sem HTTP/frontend.

### VG00.7 --- API/status mínimo

-   P0; depende: VG00.6.
-   Expor criação/consulta usando convenções HTTP já existentes.
-   Polling é suficiente no primeiro corte; SSE só em task própria se
    houver valor.
